# MERN / Full Stack — Week 1

Contains a responsive portfolio/blog UI with Header, Footer, Card, Button, and Form components. Search state filters a local JSON-like array. To keep this starter dependency-light, `index.html` loads React and Babel from public CDNs; an internet connection is required, and this is a learning demo rather than a production build. Add a separate portfolio page with personal details before submitting if the course requires both deliverables.
