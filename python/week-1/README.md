# Python — Week 1

This folder covers Python basics and control structures from the supplied course brief.

## Deliverables

- `assignments.py`: temperature conversion, grade calculator, even/odd and prime checks, and a function-based ATM simulator.
- `practice.py`: circle area, even/odd, recursive factorial, vowel/consonant counts, and Fibonacci sequence.

## Run

```sh
python3 assignments.py
python3 practice.py
```

The ATM uses a local demo PIN (`1234`) and an in-memory sample balance. Do not enter a real PIN.

The grade bands are example thresholds documented in `assignments.py`; use the instructor's rubric if different.
