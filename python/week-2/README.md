# Python — Week 2

Solutions for data structures, file handling, dictionaries, and CSV/JSON work from the supplied Week 2 brief.

## Files

- `assignments.py`: contact book, text-file word counter, JSON reader, and CSV-backed student manager.
- `practice.py`: list CRUD, word frequencies, nested-loop pattern, list extrema, and lambda sorting.

## Run

```sh
python3 assignments.py
python3 practice.py
```

The student manager stores `students.csv` beside the script. The JSON reader accepts the path to an existing JSON file.
