# Java Programming — Week 3: Collections & File Handling

Solutions for the supplied Week 3 brief: student marks in an `ArrayList` with highest and lowest, word frequency read from one file and written to another, and a mini project, an employee management system that saves and loads a text file and validates input with exceptions.

Requires Java 17 or newer. Run with `javac Main.java && java Main`. It writes `input.txt`, `output.txt` and `employees.txt` in the current directory.
