# Java Programming — Week 2: OOP Concepts

Solutions for the supplied Week 2 brief: a `Student` class, a `Vehicle` hierarchy with `Car` and `Bike` overriding methods, and a mini project, a library management system with `Book`, `Library` and `User`, showing inheritance, abstraction (an interface and an abstract class) and encapsulation.

Run with `javac Main.java && java Main`.
