Pulse component library

Every component is built only from tokens (tokens.css), so one change to a token restyles the whole product, including dark mode. States are shown side by side. Hover and focus are forced with classes here; in the prototype they come from real :hover and :focus-visible.

Buttons

40 px height (32 px small), 2 px focus ring offset 2 px, a 0.97 scale press, and a loading spinner that keeps the button's width.
