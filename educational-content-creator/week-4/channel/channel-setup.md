## About section (999 characters max; this one is 697)
```
Learn Python one small step at a time.

Short, friendly lessons for complete beginners: students starting their first programming course and anyone switching careers into tech. Each video teaches ONE idea in about 5 minutes, shows real code with real output, and ends with a tiny exercise so you practise straight away.

What you'll find here:
• Python from zero: variables, if/else, loops, functions, a mini project
• Debugging basics: how to read error messages without panic
• 30–60 s Shorts: one tip each

New lesson every week. All lesson code is free on GitHub.

Note: the presenter, Mina, is an illustrated character and the voice is synthetic; every program and every output shown is real.
```

2. **Featured video for returning subscribers:** the latest upload.
3. **Sections:** Python from zero · Shorts · Debugging basics.

## Default upload settings (Studio → Settings → Upload defaults)
* **Category:** Education. **Language:** English. **Licence:** Standard.
* **Audience:** not made for kids.
* **Captions:** upload the `.srt` with every video; it's more accurate than the automatic captions.
* **Altered or synthetic content: Yes.** The voice is synthetic, and YouTube asks creators to disclose realistic
  synthetic content. Disclosing is the honest choice even for a cartoon presenter.
