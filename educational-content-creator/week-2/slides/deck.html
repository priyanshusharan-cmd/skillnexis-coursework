The idea

A variable is a name that points to a value

age = 18
age
18

The = sign means “store”, not “is equal to”.

4
Three basic types

Every value has a type

int
age = 18

whole numbers

float
price = 2.5

numbers with a decimal point

str
name = "Mina"

text, always inside quotes

Check any value with type(…)

5
What + means

The type decides what + does

int + int
5 + 2 → 7

adds the numbers

str + str
"5" + "2" → "52"

joins the text

"5" + 2 → TypeError: Python won't guess which one you meant
6
Converting

Change the type on purpose

int("5") + int("2") # 7 str(18) + " years" # "18 years" float("2.5") * 2 # 5.0

Text from input() is always a str, so convert it before doing maths.

Names must match exactly
