# Grounded answer demo

**Question:** Which learning rate produced the lowest validation loss in the experiment?

**Allowed evidence:** the experiment's saved validation-loss table only.

**Answer format:** “The lowest observed validation loss was [value] at learning rate [rate] (epoch [n]). Evidence: [row/cell]. This comparison does not establish that the rate is best on other data.”

**If evidence is absent:** “Not available: the experiment has not been run or its result file was not supplied.”

This demonstrates a short, checkable rationale with evidence and uncertainty. It does not ask a model to reveal hidden private reasoning.
