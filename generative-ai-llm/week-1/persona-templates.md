# Prompt templates for five personas

1. **School learner:** “Explain [concept] to a [grade/level] learner. Use one familiar example, define new terms, and end with one practice question. If [source] does not support a claim, say so.”
2. **University student:** “Help me study [topic] from these notes: [notes]. Give a concise outline, key terms, and three self-test questions. Do not answer an assessment on my behalf; mark uncertain facts.”
3. **Software developer:** “Review this [language] snippet for [goal]. Return findings by severity with line references, a minimal patch suggestion, and one regression test. Separate confirmed bugs from style advice.”
4. **Small-business owner:** “Draft [asset] for [audience] using only these product facts [facts]. Follow brand voice [voice], avoid legal/health guarantees, and return [format].”
5. **Researcher:** “Summarize these papers [sources] for [research question]. Cite each point, identify methods/sample limits, and separate findings from your synthesis.”
