# Generative AI & LLMs — Week 1

This folder includes the supplied PDF's 10-example prompt evaluation worksheet and summarizer starter, plus the course-page requirements: 20 prompt templates, a tokenizer comparison, five audience-specific prompt templates, a grounded-answer demonstration, and a small writing-assistant UI prototype. The UI assembles prompt requests locally; it does not call OpenAI/Gemini or store an API key.

No model outputs or factuality scores are invented. Run a selected model locally or through an authorized provider, keep credentials outside Git, and record source text, prompt, output, and human review before completing the evaluation.
