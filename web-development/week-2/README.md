# Web Development — Week 2: CSS + Basic JavaScript

Both assignments are included, though the brief asks for any one.

1. **Interactive image gallery.** Eight images in a responsive grid, hover animations, and a lightbox with previous/next buttons, arrow keys, Esc to close and focus return. The images are gradients generated as inline SVG, so nothing is downloaded and the page works offline.
2. **Digital clock and countdown.** Live HH:MM:SS clock using `Date` and `setInterval`, plus a countdown to a chosen date, which defaults to New Year and is remembered in `localStorage`.

Open `index.html` in a browser. Motion is turned off for visitors who prefer reduced motion.
