# C++ Programming — Week 4: File Handling & STL

Solutions for the supplied Week 4 brief: write and read back a file, sort a `vector`, store roll numbers and names in a `map`, handle division by zero with exceptions, and a mini project, an employee record saver using file streams and STL containers.

Build with `c++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o week4`, then run `./week4`. It creates `week4_demo.txt` and `week4_employees.csv` in the current directory.
