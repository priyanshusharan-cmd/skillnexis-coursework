# C++ Programming — Week 3: OOP Concepts

Solutions for the supplied Week 3 brief: an `Employee` class with a salary calculation method, constructor overloading, `Shape` with `Rectangle` and `Circle`, an abstract class with virtual functions, and a mini project, an OOP-based library management system.

Build with `c++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o week3`, then run `./week3`.
