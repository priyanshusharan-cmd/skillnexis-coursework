# Data Structures & Algorithms — Week 3: Trees & Hashing

Binary search tree with search, recursive inorder, preorder and postorder traversals, a hash table built on arrays with linear probing (with tombstones for deletion), and a mini project, a BST-based contact directory with insert, search, delete and alphabetical listing.

Build with `c++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o week3`, then run `./week3`.
