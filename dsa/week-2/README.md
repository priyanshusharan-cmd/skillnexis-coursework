# Data Structures & Algorithms — Week 2: Linked List, Stack & Queue

Singly linked list with insert and delete, a stack built on a linked list, a circular array queue, reversing a linked list using stack logic, and a mini project, an undo/redo text editor simulation using two stacks.

Build with `c++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o week2`, then run `./week2`.
