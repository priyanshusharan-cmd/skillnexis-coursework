# Data Structures & Algorithms — Week 4: Graphs & Dynamic Programming

BFS and DFS, Dijkstra shortest path with a priority queue, Fibonacci by memoization and by tabulation, 0/1 knapsack that also reports the chosen items, and a mini project, a city path finder. The road distances in the city graph are illustrative values, not surveyed distances.

Build with `c++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o week4`, then run `./week4`.
