## Week 1 status and evidence

Week 1 source packs were available for 20 distinct subjects. The Data Science download duplicated the Data Analyst pack, so its folder labels that source limitation. The other five folders were prepared from their Week 1 requirements on the course site. No downloaded lecture bundles are copied into this repository.

Some deliverables require an environment or evidence that was not available during preparation: AWS account/bucket activity, IoT hardware, a Unity or Flutter build, video footage/export, Figma files, a live demo-site bug report, 3D renders/exports, and model evaluation outputs. Those folders include source, plans, or templates and clearly identify evidence that still needs to be collected. Synthetic datasets are labeled as such. No run or result is claimed unless its evidence is included.

C Programming and Python also contain Week 2 folders from earlier work. Other courses currently contain Week 1 only.
