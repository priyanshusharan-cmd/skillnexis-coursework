# SkillNexis Coursework

One repository for coursework from every enrolled subject, organized by subject and week.

## Layout

```text
python/week-1/
c-programming/week-1/
cpp-programming/week-1/
...
```

Keep each subject's weekly assignments and project in its matching folder. The course page requests a shared GitHub, Google Drive, or CodePen URL; detailed assignment instructions are provided through the batch channel.
