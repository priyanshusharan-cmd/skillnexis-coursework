# Software QA Tester — Week 1

Includes 15 login cases, 5 e-commerce checkout cases, and the bug-report template. Cases are planned and not executed. The supplied ZIP did not include a demo URL or test account, so this pack does not invent five live defects or attach fabricated screenshots. Use a permitted demo environment, record browser/device/build, execute the cases, and add only observed issues with reproducible evidence.
