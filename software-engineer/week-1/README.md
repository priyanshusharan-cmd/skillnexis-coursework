# Software Engineer — Week 1

A small JSON-backed task manager and five OOP exercises are included with design notes and repository workflow guidance. The task manager uses the Python standard library; data is stored locally in `tasks.json` when the app is run. No personal or production data is included.

## Run

`python3 task_manager.py --help` shows the commands. Add, list, update, and delete operations validate IDs, titles, priorities, and due dates. The app has not been executed as part of this coursework preparation.
