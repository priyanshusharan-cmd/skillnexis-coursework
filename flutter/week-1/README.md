# Flutter — Week 1

`lib/main.dart` is a responsive Hello Flutter profile card using `MaterialApp`, `Scaffold`, `Card`, `Column`, `Row`, and `StatelessWidget`. It includes editable sample identity and contact details and uses a built-in avatar icon because no authorized profile image was supplied.

Create a project with `flutter create app`, replace `lib/main.dart`, then run it with `flutter run`. This source has not been built in Flutter here. Replace the sample identity/contact details before using it as a personal profile.
