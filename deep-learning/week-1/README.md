# Deep Learning — Week 1

`train.py` creates synthetic linear-regression data, demonstrates tensor shapes and a train/validation split, trains a small PyTorch network with two learning rates, and saves loss and prediction plots when run. Definitions: a neuron applies weighted inputs plus a bias and activation; an epoch is one pass through training data; a batch is a subset used for an update; learning rate controls update size. This source was not executed here, so generated plots/results are not included or claimed. Requires torch and matplotlib.
