# AI Automation Engineer — Week 1

The starter set demonstrates CSV reporting, safe public API parsing, prompt templates, and a file organizer that only moves files inside a chosen folder. The digest renderer creates local HTML; it does not send email or call paid services. API availability depends on the provider. No credentials are included.

- `csv_summary.py`: summarize a CSV with standard-library Python.
- `public_api_demo.py`: request a public JSON endpoint and validate expected fields.
- `file_organizer.py`: dry-run by default; use `--apply` only after reviewing its plan.
- `daily_digest.py`: combine explicitly supplied items into a local HTML digest.
- `prompts.md`: ten structured prompt templates and optimization notes.
