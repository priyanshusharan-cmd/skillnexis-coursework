# 3D Modeling & CAD for Simulation — Week 1

The parametric OpenSCAD source in `desk_setup.scad` builds a simple desk scene with five modeled objects and a three-point light layout for a Blender render. It is designed as editable source rather than a claimed rendered/exported model.

## Use

Open the SCAD file in OpenSCAD and render/export the desk objects as STL or OBJ. For a presentation render, recreate/import the objects in Blender, assign materials, use the documented camera/light positions, set 1920×1080, and save a screenshot of the final render. No CAD application was available during authoring, so no export or render is claimed.
