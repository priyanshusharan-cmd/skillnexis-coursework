# C Programming — Week 3: Pointers & Strings

Solutions for the supplied Week 3 brief: reverse a string using pointers, count vowels and consonants, swap two numbers using pointers, allocate an array with `malloc`, and a mini project word counter using pointers and strings.

Compile with a C11 compiler: `cc -std=c11 -Wall -Wextra -pedantic main.c -o week3`, then run `./week3`.
