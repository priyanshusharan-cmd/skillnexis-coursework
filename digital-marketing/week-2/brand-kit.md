# Bean & Bloom brand kit (for Canva)

The 15 campaign assets were built in code (one template file, [design/posts.py](design/posts.py)) so every post shares exact colours, type and spacing.
To recreate or edit them in Canva, use **Brand Kit → add these values**, then pick the matching size template.

| | Value |
|---|---|
| Colours | Espresso `#3B2416` (text, dark backgrounds) · Cream `#FFF7EC` (background) · Sage `#4E6B4A` · Sage tint `#E3EBDD` · Bloom pink `#E8A0A6` (accents, large text only) · Bloom tint `#FBE3E5` · Caramel `#B9692B` |
| Fonts | Headings: *Inter Display* ExtraBold (Canva: "Inter" ExtraBold) · Body: *Inter* Medium |
| Sizes | Feed and carousel 1080 × 1350 (4:5) · Reel cover and story 1080 × 1920 (9:16). Keep text inside the central 1080 × 1420 on stories, away from UI overlays |
| Logo | Espresso circle with a pink leaf, plus the wordmark "Bean & Bloom" |
| Voice | Warm, student-friendly, practical. Benefits first ("a plug at every seat"), never pushy. One idea per post |
| Accessibility | Body text is espresso on cream (14:1). Pink is used only for large numerals and shapes, never small text. Every post has alt text in the calendar |
