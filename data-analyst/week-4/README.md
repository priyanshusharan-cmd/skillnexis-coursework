# Data Analyst — Week 4: Data Visualization & Capstone

End-to-end case study on the brief's business dataset (`financial_sample.xlsx`, 700 sales rows, Sep 2013 to Dec 2014).

1. **Clean and explore in Python:** checks for duplicates and blanks (a blank `Discount Band` is read as "None"), and checks that profit and sales arithmetic is consistent (it is on every row).
2. **Analyse with SQL:** the data is loaded into SQLite and queried by segment, country, product, discount band and year, with a pandas cross-check.
3. **Visualise:** `output/dashboard.png` has six charts, and `output/report.xlsx` has one sheet and one native Excel chart per table.
4. **Report:** `output/REPORT.md` has the findings and recommendations for a stakeholder. Every number in it is generated by `analysis.py` from the data, not typed in by hand.

**Power BI or Tableau was not used.** Power BI Desktop only runs on Windows and Tableau is not installed on this Mac, so the dashboard is built with Matplotlib and Excel instead. The charts a BI tool would show are all here, but there is no `.pbix` file and nothing is published or shared online. The brief's demo recording is also not included; `REPORT.md` is the written explanation.

Run with `pip install pandas matplotlib seaborn openpyxl xlsxwriter` and then `python3 analysis.py`.
